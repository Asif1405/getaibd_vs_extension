# GetAIBD VS Code Extension

GetAIBD is an AI-powered software engineer agent integrated directly into your VS Code lower panel. It can read your project codebase, execute file writes/edits, and code based on your direct instructions.

## Getting Started

Follow these simple steps to configure and start using the GetAIBD Agent:

1. **Get an Account:** Go to [www.getaibd.com](https://www.getaibd.com) to create your account and get a subscription package.
2. **Access Integration:** Navigate to the **Integration** menu on the website dashboard.
3. **Generate API Key:** Click to generate your unique **API Key**.
4. **Configure in VS Code:**
   - Open VS Code Settings (`Cmd+,` on macOS or `Ctrl+,` on Windows/Linux).
   - Search for **GetAIBD**.
   - Paste your **API Key** in the setting field.
   - Choose or set your model name (e.g. `claude-sonnet-4-6`).
5. **Start Coding:** Look at the bottom panel in VS Code. You will find the **GetAIBD Agent** tab next to the Terminal. Select your model and start prompt-engineering your codebase!
